## Rationale

The lead family is the valve rather than the valve core because the valve claim of [0008] needs neither a core body nor a valve stem, so it also catches the design-around 09 D9 names (placing the deflectable element in the valve stem) and any construction in which the mechanism is not packaged as a removable core. The valve core is the second independent because the value map puts the unit of sale there and because direct infringement by a core maker should not depend on the core being fitted to a stem at the point of sale. I considered making the valve core the sole apparatus independent and the valve a dependent-form claim, which would be the tidiest answer to Rule 43(2) EPC; I rejected it for the first draft because it gives up the stem-side design-around for the sake of a formal objection that can be met by election later, and I have said so in the table so counsel can elect.

The inflatable body claim is kept as an independent-in-form claim referring to the valve claim because OEM supply is a distinct point in the chain and the claim costs one line. I dropped "containing sealant" from the claim body on purpose: [0079] defines the inflatable body as containing the sealant, so the term carries it, and reciting sealant positively would make a tube maker who fits the valve but does not add sealant a non-infringer. Whether the inventor wants the positive recital is Q4; a dependent claim reciting sealant costs nothing.

The method family is kept, ranked last, because 02 rank 4 and the risk of narrowed apparatus claims justify it, and because [0015] and [0111] give it complete support step for step. Its weakness is enforcement, not support, and the table says so.

The recovery-wipe aspect of [0011] is not a family now. The description states that neither cleaning action is stated to be sufficient alone ([0010]), so a wipe-only independent claim would claim an effect the description does not attribute to the wipe alone; 08 rates that nucleus as more exposed; and a second apparatus independent to the same valve would draw Rule 43(2). The wipe is better placed as the first dependent rung and as the relationship-based formulation of Prompt 24, which keeps a supported claim whichever way 03 Q1 is answered. I record this as the choice the pre-drafting response asked for; it is not a disagreement with the Specification Drafter.

The manufacturing route, the product-by-process form, the composition and the consumable are declined as families because none has a searched novelty case (07 coverage warning; 08 N9) and each is served by a dependent rung. The seat ring as an article is the one sub-combination with a real commercial case (spare parts) and an express disclosure basis ([0095]), so it is deferred to Prompt 27 rather than declined; drafting it as a Prompt 22 independent would put a third apparatus independent into the set against no art at all. The thermal purge variant is not claimed because [0096] says it has no data and the mechanism is not described. The kit is declined because nothing in the description describes a kit; no `disclosure_requests` entry is raised because the value map makes no commercial case for one, and I will not invent one.

Statutory provisions are named for orientation only; counsel applies them.
