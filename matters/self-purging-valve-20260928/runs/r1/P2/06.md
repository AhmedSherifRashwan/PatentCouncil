**What each track has to find.** N0 is a combination: a valve member with a normal stroke and a higher-threshold over-travel; a deflectable element that the over-travel deflects; a purge gap that is closed at rest and opened by that deflection; and recovery that re-closes it. The most dangerous art is any valve, in any field, where over-travel of the closure member deforms a resilient element and opens a second flow path. Tracks 1 and 3 target that. Tracks 2, 4 and 5 target the ladder rungs. Track 6 targets fields where an examiner could find the same mechanism for a different fouling medium.

#### Track 1 — Core architecture

**Concept statement.** An inflation valve (valve core in a valve stem) for an inflatable body that contains sealant. The valve member makes a normal stroke from the valve seat at the opening pressure. Above a higher over-travel threshold it makes over-travel. The over-travel deflects a deflectable element, opening a purge gap that is closed in the rest state, so purge flow passes over the sealant-accumulation surfaces into the inflatable body. When the pressure differential falls, the element recovers and the purge gap closes (N0). With the recovery wipe of the sealing face added, this becomes N1.

## Rationale

Tracks are ordered from the nucleus outwards because the examiner will attack N0 first. The combination most likely to destroy N0 is over-travel opening a second path through a deflected resilient element, and that can come from any valve field. So the core and functional-equivalent strings are deliberately field-neutral in part (strings 2, 3, 7, 12). Strings 1, 8 and 9 stay in the tyre-valve field to catch the closest art the supplied references suggest. Ref 02's outward-deflecting lip that enlarges the flow passage is the nearest mechanism in hand, so string 8 targets its family. Ref 01's passive measures (coating, enlarged bore, insert, flare) define the "known remedies" that string 9 maps.

Avoid-list words appear only as search vocabulary: competitors' documents use them, and leaving them out would miss art. They are not proposed for drafting, so no `new_terms` entry is made.

Twelve strings, one per concept cluster, is within the 6–12 the prompt allows. Each carries at most one classification code, so a wrong code (A1) narrows only that string. Strings 3, 6, 8, 9 and 12 carry no code, so they are not hostage to a misread code.
