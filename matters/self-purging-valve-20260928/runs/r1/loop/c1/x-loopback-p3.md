## Rationale

The ruling on F-33-2 says the remedy needs no new disclosure and lies in the Claims Architect's lane, and it names the supporting paragraphs. The Phase 3 contribution is therefore narrow: state the sub-combination the Description already contains as a candidate the Gate 2 delta can confirm in one line, and find anything in the text that would defeat that family once drafted. The obstacle is the definition of "deflectable element" in [0048]. It defines the element through the purge gap, and [0011] says every first-aspect feature applies to the recovery-wipe aspect. Without a consistency sentence, a claim to the aspect of [0011] that uses the defined term would be read as requiring a purge gap after all, and the design-around would stay open. That is why AE-1 asks for the definition to be made consistent rather than for a new embodiment.

AE-2 is included because the same gap exists in the method category. [0015] makes the recovery wipe an add-on to the purge method, so a method-only competitor, for example an inflation-device maker inducing use, would be outside every method claim if the valve has no purge gap.

AE-3 is included because a design-around finding should close the route, not only the version of it the reviewer wrote down. A competitor who reads a recovery-wipe claim will next ask whether the wipe can be dropped too. The answer depends on whether the inventor conceived seat deflection enlarging the main flow passage. The disclosure does not say so, and [0046] points the other way. So AE-3 is offered as new matter for Gate 2 and not implied from the first embodiment. It is written in locked terms so that no new term is needed. "Purge gap" is deliberately not stretched: redefining a locked term to cover a series path would contradict [0032] and [0046] and invite an added-matter objection at the EPO.

Nothing already confirmed is weakened. The purge-gap family of claims 1, 2 and 4 stays as it is; AE-1 and AE-2 add a parallel family. No narrowing is proposed.

## Assumptions

A1. The design-around as the reviewer describes it keeps the recovery wipe (the finding's attack: "wipes the sealing face on recovery"). AE-1 closes it fully only on that basis. Not blocking.

A2. [0048] and [0011], read together, would be taken to import the purge gap into a claim that uses "deflectable element". This is a reading of the text, not a ruling, and the Specification Drafter may judge the risk differently. Not blocking; it sets the disclosure request.

A3. The confirmed first, second and third embodiments each produce the recovery wipe ([0117]), so AE-1 needs no embodiment beyond them. Not blocking.

A4. An interrupted purge shoulder formed as lugs ([0119]) would let inflation gas pass the expanded upper edge in AE-3. This is a mechanical reading offered for Gate 2, not a stated fact. It blocks AE-3 only.
