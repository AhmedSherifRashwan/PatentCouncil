## Rationale

The audit is organised by scope element so that the compose step can walk it in section order and the Claims Architect can read it by rung. Two elements are critical and both are inventor-only: the purge gap mechanism (EN-1) and the threshold measuring condition (EN-3). I did not soften either, because a description that resolves them by choosing a plausible reading would state an invented fact, and both offices judge sufficiency on the filed text.

I separated "enabled at genus level" from "enabled as the prototype". Several rungs (two-rate characteristic, retention, shape-setting) are within ordinary skill once the function is stated, so the genus is enabled even where the prototype's own construction is unrecorded; the cost is a thinner worked example, and I graded those medium rather than high. The deflectable element genus is the reverse: the principle is clear, but only one species was built and the second is one sentence, so I graded the F1 genus medium and an N4-B rung of its own high.

Experiments are recommended only where a statement the inventor may want (service life, CO2 use, range criticality, attribution of the effect) cannot otherwise be made. None is a precondition for filing the description as narrowed here.

The thermal purge variant is graded high for itself and low for everything else, to make plain that recording it is safe and claiming it is not.
