# Top-10 inventor questions — self-purging-valve-20260929

Ranked by how much the answer would change claim scope. Full list of twenty-five questions is in `runs/r1/P1/05.md`; this is the short form for the inventor to answer directly. Pick one option or write "Other". This is a drafting and analysis aid; qualified patent counsel signs off on anything filed.

---

**1. Does the self-purging effect need the snap-back wipe, the air purge, or both?**

- [ ] A. Both are required — neither alone is sufficient
- [ ] B. Air purge alone is sufficient; the wipe is a helpful but non-essential bonus
- [ ] C. The wipe is required; air purge alone would not clear the sealant film
- [ ] D. Other: ______________________

*What each answer changes:* A keeps shape recovery as an essential limitation of the independent claim. B lets the independent claim drop any recovery/wipe limitation and cover embodiments with a weak or no wipe (broadening scope to Alternative A). C forces a "resiliently recovering" seat limitation into the independent claim. D leaves scope tied to the built NiTi embodiment only, pending further testing.

---

**2. Which surface bounds the purge gap, and how does the seat ring's interference fit coexist with the purge gap opening on the same surface?**

- [ ] A. The core body bore bounds the gap; the interference fit is only at the locating shoulder, and the free length of the seat ring wall is what expands into a relief in the bore
- [ ] B. The valve stem bore (not the core body bore) bounds the gap
- [ ] C. The fit runs the full length of the ring but is light enough to release once the ring expands past a certain radius
- [ ] D. Other: ______________________

*What each answer changes:* A confirms the drafting team's working assumption and lets the geometry be drawn and claimed as one consistent structure. B requires re-drafting every passage (and the terminology lock) that currently assumes the core body bore. C introduces an undisclosed releasing-fit mechanism that would need new supporting description before it could be claimed.

---

**3. Could the over-travel differential be set by something other than the two-rate return spring — for example by the seat ring's own resistance to further poppet travel, or a mechanical stop?**

- [ ] A. No — the two-rate spring is the only workable way identified
- [ ] B. Yes — the seat ring's own resistance could plausibly set or contribute to the threshold
- [ ] C. Yes — some other spring or stop arrangement (not yet disclosed) could also work
- [ ] D. Other: ______________________

*What each answer changes:* A keeps a two-rate return spring as an essential limitation of the independent claim. B or C let the threshold be claimed as a functional limitation not tied to a spring, closing the design-around already flagged as the most exposed sub-mechanism (commercial value map row 5).

---

**4. Is the invention limited to a Presta-pattern, removable valve core, or does it also cover other valve standards and/or a non-removable construction?**

- [ ] A. Presta-pattern, removable core only
- [ ] B. Any removable valve-core standard (Presta, Schrader, etc.), same mechanism, different body form
- [ ] C. Removable or integral — the seat ring/poppet/purge gap mechanism does not depend on the core being removable
- [ ] D. Other: ______________________

*What each answer changes:* A keeps the valve stem and valve core claim language narrow to the Presta pattern. B broadens that language to a functional genus covering other standards. C additionally removes "removable" as an implicit limitation.

---

**5. Is a non-superelastic but elastically recovering seat ring (e.g. the polymer seat ring of Alternative A) an embodiment you intend to pursue as part of the core invention, not just a cheaper fallback line?**

- [ ] A. Yes — treat it as an equally valid embodiment of the same invention
- [ ] B. No — it is a lower-cost fallback only; the core concept is the superelastic seat ring
- [ ] C. Possibly, but only if testing shows it still clears the sealant film adequately
- [ ] D. Other: ______________________

*What each answer changes:* A lets the independent claim use a genus (radially compliant, elastically recovering seat element) with the superelastic seat ring as a dependent species. B forces a superelastic (or equivalent recovery) limitation into the independent claim, narrowing scope but reducing enablement risk on the polymer variant. C defers the breadth decision to Gate 2/3.

---

**6. Was any seat-ring geometry other than the convoluted wall considered for converting axial load into radial expansion?**

- [ ] A. No — the convoluted wall is the only mechanism designed or considered
- [ ] B. Yes: ______________________ (describe)
- [ ] C. Not considered yet, but plausible alternatives may exist
- [ ] D. Other: ______________________

*What each answer changes:* A keeps the convoluted wall as the claimable structure, limited to what was actually conceived. B, with a concrete alternative named, lets the independent claim use a broader functional wall limitation with the convoluted wall as a dependent species — closing a gap Invention Analyst's Phase 3 work would otherwise have to flag as open.

---

**7. Is over-travel intended to occur on every normal inflation with an ordinary floor pump, or only above a certain tyre pressure or with certain pump types?**

- [ ] A. On every normal inflation with any ordinary floor pump
- [ ] B. Only above a certain target tyre pressure
- [ ] C. Only with certain pump types (e.g. floor pumps but not mini-pumps)
- [ ] D. Other: ______________________

*What each answer changes:* A supports an unqualified "during inflation" method step. B or C require the method claim and any "in use" device language to be qualified by pressure or pump type, narrowing the claim but avoiding an enablement or functional-language attack on the unqualified version.

---

**8. In the two-piece seat of Alternative B, does the wiper ring's outward deflection actually open a purge flow path, and if so where does it run relative to the rigid seat?**

- [ ] A. Yes — deflection opens an annular gap around the wiper ring, similar in principle to the one-piece design
- [ ] B. Yes, but the path runs somewhere different: ______________________
- [ ] C. Not sure — it was a discussed concept, not a designed one
- [ ] D. Other: ______________________

*What each answer changes:* A or B let Alternative B be written up as a genuine alternative embodiment with its own supporting description, closing the "split the seat function" design-around. C means Alternative B stays undisclosed beyond the concept level and cannot yet support a claim.

---

**9. For the section 4 dimensional and pressure ranges, are the stated endpoints based on a build, a calculation, or belief only? Is there an intended range for the normal stroke (currently a single value only)?**

- [ ] A. Endpoints are calculated or engineering estimates, not yet built
- [ ] B. Endpoints are belief or experience only, with no calculation behind them
- [ ] C. Some ranges have a stated basis (specify which), others are belief only
- [ ] D. Other: ______________________ — and normal stroke range (or "single value only"): ______________________

*What each answer changes:* A supports drafting the ranges as an intended operating window with an engineering rationale, strengthening enablement. B means each endpoint should be carried as a candidate pending Gate 2/3 confirmation, and possibly narrowed nearer the built prototype. A stated stroke range (versus none) lets that parameter be claimed as a range rather than left as one unsupported value.

---

**10. Should the thermal, hand-warm purge variant (Alternative C) be developed as a claimed embodiment, kept only as background, or dropped?**

- [ ] A. Pursue it — draft as a separate embodiment or claim family even without test data, clearly flagged as unconfirmed
- [ ] B. Keep it in the description as a discussed alternative only, not a claimed embodiment
- [ ] C. Drop it entirely — not part of this application
- [ ] D. Other: ______________________

*What each answer changes:* A keeps open a pump-free claim family (commercial value map row 9) and directs the specification to describe it with enough structure to be enabling. B keeps it as background disclosure that can still block a competitor's design-around, without committing claim scope to it. C removes it from the matter entirely.
