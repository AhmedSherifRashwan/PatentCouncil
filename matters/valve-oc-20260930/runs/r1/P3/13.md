No value outside the inventor's stated broad range is proposed for any parameter, and no range is proposed at all for a parameter that has no stated range to interpolate from.

## Rationale

I split the parameters into four tables by evidential status rather than by component, because the confirmation posture is what Gate 2 needs to act on quickly, and it differs sharply between them:

- **Table 1** covers the only eight parameters where the disclosure itself gives more than one number: a "believed" broad range and a built prototype value (§4). These are the only parameters for which an intermediate/preferred ladder can be interpolated without inventing new facts, because interpolation stays strictly inside the inventor's own stated bounds. I used one fixed, disclosed method (60%/25% of the span, centred on the prototype value, clipped to the disclosed endpoints) across all eight rather than judgement calls per parameter, so that Gate 2 can audit the method once rather than parameter by parameter. Two rows in this table carry an extra warning: over-travel distance and purge gap opening were not independently measured in the bench test (01 (h) says so explicitly), and the purge gap's location is internally inconsistent in the disclosure (01 Q1, Q2). I did not attempt to resolve that inconsistency with a plausible mechanism; a wrong guess here would misdescribe the one feature the enablement of the whole nucleus turns on (03, Table "Feature Classification", row C6/C7).
- **Table 2** covers parameters where only a single value exists and no range, tolerance or second data point is given anywhere in the dossier. I did not propose bands for these, because there is nothing to interpolate from and any number I supplied would be fabricated engineering data, which the brief expressly forbids. The thermal-variant Af (35–40 °C) is the one exception with two numbers, but I kept it in Table 2 rather than Table 1 because no ring was ever built to it (§6) and it belongs to a candidate concept (the thermal variant, F5) that sits outside the N0 nucleus (03) and that the inventor has already expressed doubt about pursuing.
- **Table 3** covers the bench-test parameters. Unlike Tables 1 and 2, most of these are genuinely measured (n = 3 per group) rather than believed or interpolated, so I marked the fixed test conditions (pressure, duration, temperature, sealant volume, the two failure thresholds) as not needing confirmation — they are simply what was run — while marking the outcome measurements (leak-down, inflation time, cycles) as needing confirmation only in the narrow sense that three units is a small sample and the prototypes were not run to failure, so the true spread and the true fatigue life are unknown (01 (l), §9).
- **Table 4** lists parameters the disclosure names in principle (through the mechanism description) but gives no value for at all — spring rates, the sealing face angle, the purge shoulder's clearance, the core body bore, and the NiTi transformation temperatures other than Af. I judged it more useful to list these explicitly, each tied to its open question, than to omit them; a missing row would look like an oversight rather than a genuine gap in the disclosure.

I did not attempt to weight the ladders by commercial value, because Prompt 02 was not available; Claims Architect should reconcile which rungs matter most once it is.

## Assumptions

A1. Intermediate and preferred ranges in Table 1 are generated by a fixed interpolation rule (60%/25% of the disclosed span, centred on the prototype value, clipped to the disclosed endpoints) rather than by engineering judgement per parameter, so that the method is auditable in one place. This is a drafting proposal only. Blocking for P4 and P5 until Gate 2 confirms or replaces these bands.

A2. The prototype dimensional values in Table 1 (seat ring inner diameter, wall thickness, free length, convolution amplitude) are treated as built/manufactured representative values because §7 describes the ring as machined and shape-set to these figures. Not blocking.

A3. The prototype functional/dynamic values in Table 1 (over-travel distance, purge gap opening, crack pressure, over-travel threshold, and Table 2's normal stroke) are treated as design/target values rather than measured values, because none is stated as independently measured; over-travel distance and purge gap opening are expressly flagged "not measured in the test" in 01 (h), and the audible snap in the bench data is an indirect indicator only (01 A9). Blocking for P4 until Q3 below is answered.

A4. Seat ring outer diameter (2.7 mm, Table 2) carries forward 01's Assumption A2: it is inferred from the tube stock named in §7, not asserted by the inventor as a ring dimension. Blocking for P4.

A5. The Table 3 test conditions (pressure, hold duration, hold temperature, sealant volume, the two failure thresholds) are treated as evidenced by the test protocol itself (§8, bench data) and not requiring confirmation as values; whether the effect holds at other pressures, temperatures or with other sealants is a separate, already-open question (01 Q23, Q28, Q29), not a defect in these values. Not blocking.

A6. The Table 3 outcome measurements (leak-down, inflation time, cycles) are treated as genuinely measured, evidenced data (bench data), not as proposed or believed values, but flagged for confirmation only because the sample is n = 3 and the prototypes were not run to failure (01 (l)). Not blocking.

A7. Locked terminology (terminology/LOCKED.md) is used verbatim throughout; parameters this table needed that are not themselves locked terms (process sub-parameters, test sub-parameters, and geometric parameters with no disclosed value) are declared in `new_terms`, each mapped to the nearest locked term or marked as a genuinely new sibling concept. Not blocking.
