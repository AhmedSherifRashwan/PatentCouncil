## Rationale

**Why Formulation 2 leads.** The description now contains, in [0013], [0043], [0045] and [0047], the state definitions Formulation 2 needs, in the very words: closed, normal-open and purge states each tied to a pressure differential band, the ring element "at rest" or "in its at-rest form" in the two lower states, the purge gap "associated with the deflectable ring element", the purge flow path "separate from the main passage" ([0043]). That makes Formulation 2 the broadest wording with verbatim support, and it closes the design-arounds `24` listed (any formation of the poppet, any threshold-setting arrangement, any gap location or deflection direction, Alternative B). `22` claim 1's "spaced from" is kept as the first rung because it is the teardown-provable version and the file should hold both readings of the normal-open state.

**Why the threshold band wording changed.** `24` wrote "below" and "above" the over-travel threshold; the description's own definition [0013] says "does not exceed" and "exceeds". Using the definition's words removes a gap at exactly the threshold and ties the claim to the definitions section, which is where an examiner will look for the meaning of the states.

**Why the method claim is carrier-neutral.** Formulation 3 as drafted in `24` required "a valve core comprising a core body". The description discloses an inflation valve with no core body ([0138]) and the method is where a competitor's product of any construction is caught by what it does, so the preamble names only the poppet, the ring element, the main passage and the return spring. "Surfaces on which sealant film accumulates" is the [0056] phrase and states the technical effect the EPO looks for; `24` marked it droppable and it remains so.

**What was added and why.** The description describes the alternatives that `22`/`23` could only request; each is now a rung with its anchor, because a rung a competitor's product would fall on is worth a claim number, and because each is a corresponding structure for the functional terms (deflecting formation, threshold-setting arrangement, deflectable ring element) that the US will read under 35 U.S.C. §112(f). Claim 46 (mechanical over-travel, [0066]) and claim 88 (deflation purge, [0067]) are new rungs that answer d2 R5 in part; a full answer would be an independent claim without the pressure threshold, which is a family decision recorded in Open Questions rather than made here.

**What was declined.** A kit claim ([0141]) and a replacement valve core claim ([0140]) as independent claims: `21` deferred both to Prompt 27 and the description's support does not change the commercial reasoning. A thermally actuated purge rung ([0142]): outside the nucleus, prophetic, and the description itself calls it a separate concept. A lock nut rung ([0041]): conventional and the description says it takes no part in the cleaning actions. Purge sleeve, return-spring retainer and inverted arrangement ([0116], [0117]): described, but each is a paragraph of one sentence and the inverted arrangement is described as not preferred; they remain available for amendment and are noted for Prompt 27. A "single inflation event" apparatus rung: a use condition, carried in the method (79, 87).

**Numbering.** `22` reserved final numbering to this prompt. The map in the Audit lets every `22`/`23` rung be traced; from here on numbers are stable and revisions mark changed claims only.

**Water quenching.** The one narrowing applied for support. The description gives water quenching alone ([0148]); a generic quench would be a limitation without an anchor. The disclosure request restores the genus if the drafter can support it.
