## Deliverable

### Abstract

A valve core for the inflation valve of a bicycle inner tube or other inflatable chamber holding liquid sealant has a core body (20), a poppet (40), a deflectable ring element such as a seat ring (30), and a return spring (50). In a closed state a sealing face (42) rests on a sealing edge (34), and a main passage (64) and a purge gap (60) are closed. Through a normal stroke the main passage opens while the purge gap remains closed. When the poppet moves beyond the normal stroke into over-travel, a purge shoulder (44) bears on the deflectable ring element and deflects it radially, opening the purge gap so that inflation gas flows along a separate purge flow path (62) across the surfaces on which sealant film accumulates. When the poppet returns, the deflectable ring element undergoes shape recovery, closes the purge gap and shears sealant film from the poppet.

## Rationale

Word count: 139 words excluding the ten reference signs, 149 words including them; within the 50 to 150 word limit on either count, and within the EPO guideline of about 150 words.

The abstract is drafted from `description.v2.md` and `claims.v2.md` only. It states the technical field ([0001a]) and the core solution of independent claims 1, 61, 69 and 92: three states of one poppet, a purge gap opened only in over-travel by radial deflection of the deflectable ring element, a purge flow path separate from the main passage, and shape recovery that closes the purge gap and shears sealant film (the snap-back wipe of claims 26, 27 and 61). The deflectable ring element is named generically, with the seat ring as the illustrated species, so that the abstract covers both the seat-ring embodiment (claims 1 and 9) and the fixed-seat-and-wiper-ring embodiment (claim 10) without listing either as a limitation.

Reference signs are included in parentheses because the default jurisdictions include the EPO and the UK, where Rule 47(4) EPC and the corresponding UK practice require each main technical feature illustrated in the drawings to carry its reference sign in the abstract. US practice permits reference signs and the same text serves all three jurisdictions; if counsel prefers a US abstract without them, deleting the parentheses leaves 139 words and changes nothing else. Fig. 3 (purge state) is the figure that should accompany the abstract, since it shows every numbered feature named except the sealing edge (34) resting under the sealing face (42), which Fig. 1 shows.

Deliberately omitted: the pressure-differential mechanism (crack pressure, over-travel threshold) and mechanical depression, because the independent claims of the valve core and the inflation valve (claims 1 and 69) cover both and the abstract should not suggest either is essential; materials, dimensions, the convoluted wall, the two-stage return spring, and the methods and kit, which are dependent or secondary claim categories. No claim-style language, no "means for", no "the invention", no statement of merit.

The list of figures (`list-of-figures.md`) has one line per numbered figure, with lettered sub-views described within the line, and uses only the figure numbers, states and reference numerals that the description's brief description of the drawings ([0001g] to [0001u]) and detailed description use. All alternative-embodiment numerals in the list were checked against the description text.
