A valve core for the inflation valve of a bicycle inner tube or other inflatable chamber holding liquid sealant has a core body (20), a poppet (40), a deflectable ring element such as a seat ring (30), and a return spring (50). In a closed state a sealing face (42) rests on a sealing edge (34), and a main passage (64) and a purge gap (60) are closed. Through a normal stroke the main passage opens while the purge gap remains closed. When the poppet moves beyond the normal stroke into over-travel, a purge shoulder (44) bears on the deflectable ring element and deflects it radially, opening the purge gap so that inflation gas flows along a separate purge flow path (62) across the surfaces on which sealant film accumulates. When the poppet returns, the deflectable ring element undergoes shape recovery, closes the purge gap and shears sealant film from the poppet.
